# Asset credits

Terrain, character sheets, diver/robot animation frames and decorative icons: **Kenney Pixel Platformer 1.2**, https://kenney.nl/assets/pixel-platformer, Creative Commons Zero (CC0). See `assets/KENNEY-LICENSE.txt`.

The workshop map, pixel lettering, procedural harbor backdrop, five WAV effects, 24-second WAV music loop and MIDI score were authored for this project and are supplied under the MIT license in LICENSE. Audio uses synthesized oscillators, without third-party recordings or sample banks. No AI image generation was used.

The game streams `assets/audio/harbor.wav`. The MIDI version is supplied for optional editing in a music sequencer. All runtime assets are ready to use; no asset build step is required.
